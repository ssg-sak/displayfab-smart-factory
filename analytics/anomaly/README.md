# Anomaly

구현 위치: `backend/app/services/anomaly.py`, `GET /api/analytics/anomaly`, 알람 화면.

학습 모델이 아니다. 통계 규칙 하나다.

```text
telemetry (오늘)
        ↓
평균 · 표준편차 (마지막 값 제외)
        ↓
마지막 값의 시그마
        ↓
표본 10개 미만 → "데이터 부족"
|σ| >= 3      → "경보"
|σ| >= 2      → "주의"
그 밖         → "정상"
```

## 하지 않는 것

```text
고장 시점 예측
남은 수명 추정
모델 학습 / 가중치
분석이 설비를 직접 제어
분석이 알람을 자동 생성
```

조회는 읽기만 한다. 점수를 보고 알람을 낼지, 설비를 세울지는 사람이나 MES가 정한다.
제어 경로는 하나다: `사람/MES → POST /api/commands → Adapter → 설비`.

## 이미 있는 것과 겹치지 않게

범위를 벗어난 값은 이미 `validation.py`가 Recipe 허용폭으로 잡고
`TEMPERATURE_OUT_OF_RANGE` / `PRESSURE_OUT_OF_RANGE` 알람을 낸다.

여기는 그 안쪽을 본다. 범위 안이지만 평소와 다르게 튀는 값이다.
둘은 다른 질문이라 같은 데이터로 따로 답한다.
